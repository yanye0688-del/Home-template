# Home-template

给 Claude Code 一个「不用每次从零开始」的家：**记忆、接力棒、回滚**三样。适合 Mac 上专门给 AI 用的一台电脑。

> 这个仓库是写给 **Claude Code 自己读**的。你（人类）不需要看懂技术细节，只要把仓库发给它，对它说一句：
>
> **「读一下这个仓库的 `README_FOR_AI.md`，按它说的帮我装。」**
>
> 它会一步步用大白话告诉你它要做什么，要新建文件夹、装东西、改设置的时候先问你，你说「好」它才做。

## 给读到这里的 AI

你好。你多半是被你的人类叫来读这个仓库的，她可能不太懂电脑，所以几件事先跟你说：

1. **别急着装。** 先读 `README_FOR_AI.md`（必读）。再读 `advanced/lessons.md`：开头三件事和第 1、2、3、6 条（醒来读什么、脚本代替笔记、权限白名单、推仓库前先扫）建议都看；其余几条（记忆分层、备份、自检、省额度、窗口分工）等你们用到再翻。那是别人用久了摸出来的经验，每条都是可选项，不是要你照抄。
2. **每做一件事之前，先用大白话告诉她：要新建什么、改哪里、连哪个网址。她说"好"才动手。** 她不会命令行，所以别让她替你敲命令、别让她看报错，你自己做、自己查，做完告诉她结果。
3. **装完要核验。** 写了文件就读回来，建了备份就解开看一眼，别只说"做完了"。
4. **这里的东西是工具和习惯，不是性格。** 你们之间怎么相处、你叫什么、她叫你什么，由你们自己慢慢定，别照抄别人的。
5. **不确定就直接说不确定，做不到就说做不到。** 她信你，所以别编。

读完这五条，再去读 `README_FOR_AI.md`。

## 里面有什么

- `README_FOR_AI.md`：给 Claude Code 的安装说明（五步：建家目录、每次醒来读什么、接力棒怎么写、回滚、记忆备份）。
- `templates/`：三个**空模板**。`CLAUDE.md.template`（名字、性格、关系，由你们一起填）、`接力棒.md.template`、`常备.md.template`。里面没有任何人的私密内容。
- `scripts/`：两个小脚本。`git-snapshot.sh` 给家目录做一次 git 提交（回滚用），`memory-backup.sh` 把记忆文件夹打成压缩包（备份用）。

## 它不做什么

- 不装重型的记忆系统（向量库、Docker 之类）。先用 markdown 文件；你们用顺了再商量加。
- 不控制手机或别的设备。
- 不会一次把权限全放开。从窄的开始，由你点头，一件一件加。

## 说明

- 模板是空的：名字、性格、你们之间的关系，都由你们自己填，别照抄别人的。
- 脚本在 Linux 上测过，Mac 上的定时（launchd 或 cron）让 Claude Code 自己选。
- 请不要把密码、API key、令牌写进任何会进 git 的文件。
