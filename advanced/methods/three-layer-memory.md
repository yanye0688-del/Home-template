# 三层记忆，各有一个权威来源

| 层 | 放什么 | 不承担什么 |
|---|---|---|
| 经历/事实 | 逐字原话、来源与日期、为什么重要；由实际记忆后端或本地原文档案保存 | 不写成每天重复注入的长指令 |
| 当前现场 | 接力棒：现在停在哪、当前状态、未闭环和下一步；引用原文位置 | 不复制整段经历，不变成长篇流水账 |
| 稳定做法 | 身份配置、约定好的行为习惯、取回入口 | 不把临时情绪和每次犯错都永久钉住 |

“同一件事只落一层”指原文只有一份权威副本；其他层可以写短引用和行动提示，不是禁止引用。原话进入档案后，接力棒写当前停点和准确的取回引用，不再复制整段。

新事实优先。发现冲突时核对来源，必要时问当事人；不要偷偷取一个版本。承诺优先放有状态的待办，完成就关闭，不永久挤占常备。

删除、压缩 Markdown 前，先逐字存档旧段，连同原日期标题，重新读取核对后才修改。快照和自动衰减不能替代可读档案。删除与整理都不是为了让记录看起来漂亮。

写行为习惯时留下触发条件、动作、完成条件和取回入口。既记录需要纠正的事，也记录确实做对、值得保留的做法。
